<CardGrid stagger>
  <Card title="Typed protocol" icon="seti:typescript">
    Declare actions, requests and streams once with Zod, Valibot or ArkType (Standard Schema). Every
    message is validated on receipt and typed end to end.
  </Card>
  <Card title="No server by default" icon="rocket">
    Peers find each other through public Nostr relays with encrypted ephemeral events and talk
    directly over WebRTC. Relays learn a topic hash and traffic volume, nothing else.
  </Card>
  <Card title="A ladder, not a cliff" icon="random">
    Each peer pair climbs direct → TURN → data relay. With your own Beamhop relay, symmetric NATs and
    corporate firewalls stop being dead ends.
  </Card>
  <Card title="Everything you need for apps" icon="puzzle">
    Mesh and host-authoritative star topologies, reliable and unreliable channels, chunked file
    streams, calls, LWW maps and logs for shared state, and React hooks.
  </Card>
  <Card title="One relay binary" icon="setting">
    `beamhop-relay` is a full Nostr relay, a TURN server, a data relay, Blossom media and Lightning
    payments in one Bun process, with a mobile-first admin UI.
  </Card>
  <Card title="See what the network does" icon="magnifier">
    The telemetry bus reports paths, RTT, bytes per channel and transfer progress. Studio turns it
    into a topology graph, timeline and fault injector.
  </Card>
</CardGrid>
